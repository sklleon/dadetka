# Квитанции публикаций Да детки

Служебная ветка для долговременных попыток/ID публикаций (#858).
Pages и контентные workflow из неё не запускаются.
Записи receipts/*.json содержат идентичность, хеш задания, статус, ID/ссылку.
Тексты, медиа и токены сюда не записываются. pending/unknown требуют сверки.
